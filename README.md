# 燕云十六声数值体系拆解与蒙特卡洛模拟分析

《燕云十六声》（网易，开放世界武侠 ARPG）PVE 战斗数值体系的可复现模拟分析仓库。
以**公式逆向拆解 + 解析推导 + NumPy 蒙特卡洛模拟互验**的方法，量化三率系统边际收益、
词条价值与乘区稀释、调律随机养成的保底机制设计。配套报告为《燕云十六声数值体系拆解报告》。

## 核心结论

1. **三率系统存在"满覆盖断点"**：会心+会意凑满 100% 的瞬间白字清零、期望伤害跃升 **+8.4%**；
   过线后会意边际收益骤降约 **49%**（挤压区内多余率值只在会意/会心间重新分配）。
   满覆盖是最优配装的第一优先级。
2. **加算/乘算分区是控制数值膨胀的核心手段**：已有 45% 增伤时，一条 +10% 增伤实际收益仅
   **6.90%**；词条价值排序为 最大本系属攻(+2.81%) > 最大外功(+1.96%) > 最小本系属攻(+1.69%)
   > 最小外功(+1.18%)。
3. **调律保底的本质是体验方差管理**：动态保底降均值仅 −27%，但砍右尾 P99 −36%、最坏情况
   −37%；变音自选（6 次硬保底）把完美毕业成本确定性化，硬上限 **48 件**。

## 仓库结构

```
├── src/
│   ├── damage_model.py     # 伤害公式解析期望模型(四层乘区: 基础/修正/判定/增伤)
│   ├── monte_carlo.py      # NumPy 向量化蒙特卡洛模拟器(千万次级)
│   └── pity_system.py      # 调律模拟: 纯随机/动态保底/动态保底+变音自选
├── experiments/
│   ├── exp1_three_rates.py # 三率边际收益+满覆盖断点+挤压区扫描+稳定性 → fig1, fig3
│   ├── exp2_affix_value.py # 词条边际收益+加算稀释 → fig2
│   └── exp3_pity_cost.py   # 2万玩家×8件装备毕业成本三机制对比 → fig4
├── tests/                  # pytest: 解析解×蒙特卡洛互验、保底机制性质
├── results/                # 实验自动生成的 CSV/JSON + 锚点对照
└── figures/                # fig1~fig4 (中文标签, 300dpi)
```

## 复现步骤

```bash
pip install -r requirements.txt

# 三个实验可独立一键运行, 自动生成 results/ 与 figures/
python experiments/exp1_three_rates.py
python experiments/exp2_affix_value.py
python experiments/exp3_pity_cost.py

# 测试(解析解 vs 蒙特卡洛互验误差<0.1%、判定概率归一性、保底硬上限等)
pytest tests/ -q
```

所有随机模拟使用 `numpy.random.default_rng(20261227)` 固定种子，结果可完全复现。

## 局限性声明

- **判定顺序存在社区争议**：本仓库按报告的"先会意→精准→会心"实现（少数社区攻略口径）；
  多数信源（3DM、游民星空、网易云游戏）为"先精准→会意→会心"模型。由于会意不依赖精准命中，
  两种顺序在数学上基本等价，差异仅在会心+会意=100% 临界区附近显著，不影响本文主要结论。
- **"基础/修正/判定/增伤"四区命名为再加工框架**：伤害公式的机制本身有多信源确认，
  但四区命名未见任何官方/社区信源原文使用，属于分析框架。
- 公式与概率参数（30% 调律概率、boss 防御 39、会心 1.5/会意 1.35 等）来自社区实测逆推，
  官方未完整公示；面板参数为合理估值，**结论方向性稳健、绝对值仅供量级参考**。
- 调律成本表中"最大值"为 16 万件装备样本的单种子尾部极值，本身波动大，应以均值/P99 为准。
- 后续方向：实机采样回归验证参数、PVP 公式对比、气竭窗口最优输出排轴、交易行通胀分析。
